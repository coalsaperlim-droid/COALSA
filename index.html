☁️ Firebase — Sincronización entre dispositivos

Ej: https://perlim-gestion-default-rtdb.firebaseio.com
📖 ¿Cómo crear Firebase gratis? (Guía paso a paso)
Paso 1: Ve a console.firebase.google.com con tu cuenta Google
Paso 2: "Agregar proyecto" → nombre: perlim-gestion → desactiva Analytics → Crear
Paso 3: Menú izquierdo: Compilación → Realtime Database → Crear base de datos
Paso 4: Cualquier región → Siguiente → selecciona "Modo de prueba" → Listo
Paso 5: Copia la URL que aparece (termina en .firebaseio.com)
Paso 6: Pestaña "Reglas" → borra todo → pega:
{ "rules": { ".read": true, ".write": true } } → Click Publicar
Paso 7: Vuelve aquí, pega la URL y click "Conectar"
